One letter for your day — exactly one character, A to Z, standing for the
word that describes the day. `LETTER.txt` holds the letter; `main.ts` checks
it is a single capital letter and writes exactly that one byte to
`/output/entry.txt` for the judge to read. No word, no gloss, no punctuation,
not even a newline: the gate allows 1 to 1 characters.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
